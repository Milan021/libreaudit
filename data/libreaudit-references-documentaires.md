## UTILISATION DANS LIBREAUDIT

### Logique d'affichage dans le rapport PDF

Quand le prospect déclare un outil (ex: "Oracle Database"), le rapport doit :

1. **Section "Alternatives"** → afficher l'alternative recommandée (PostgreSQL) avec le scoring
2. **Section "Économies estimées"** → calcul basé sur la redevance déclarée × taux catégorie
3. **Section "Références de migration"** → puiser dans ce fichier :
   - 2-3 case studies pertinents (même secteur si possible)
   - 1 livre blanc / guide de migration téléchargeable
   - 1 benchmark technique
4. **Section "Ressources"** → liens vers documentation, whitepapers, et témoignages

### Priorisation des ressources
- **Secteur bancaire/assurance** → privilégier les case studies finance (LATAM, banque Tier-1, assureur Deloitte)
- **Administration publique** → privilégier Gendarmerie, DINUM, Schleswig-Holstein, GLPI ministères
- **Santé** → privilégier IHR LABOR (Zimbra), Apollo Hospitals (PostgreSQL)
- **Industrie** → privilégier Uratom Solar (ERPNext), fournisseur auto (SAP), Golden State Foods
